# Changelog

## 0.2.0 — local implementation, 2026-10-06

- Add canonical methods, research/replication/improvement recipes and three
  study-local host entrypoints.
- Add closed evidence schemas, capability/configuration resolution, exact
  bundles, frozen campaigns and content references.
- Add bounded local execution with append-only attempts, failure/interruption
  recovery, recomputation, claims and revision-specific deterministic review.
- Add explicit update reconciliation, validation, transactional adoption,
  historical resume, rollback and separate three-way scaffold migrations.
- Add a no-account toy study, replacement comparisons, conformance and
  contributor/governance materials.

This is the first implementation. There is no migration promise for prior
unimplemented designs. See [release scope](docs/releases/0.2.0.md).
