# Code of conduct

Treat participants with respect. Discuss ideas and evidence rather than
attacking people. Welcome different backgrounds and levels of experience.
Give actionable feedback and acknowledge corrections.

Harassment, threats, discriminatory abuse, unwanted sexual attention and
publishing another person's private information are unacceptable. These rules
apply in project spaces and when representing the project publicly.

The maintainer handles reports and may remove content, limit participation or
exclude a participant when needed. Report concerns privately through the
maintainer's published GitHub profile contact options; do not put sensitive
personal information in a public issue. The maintainer will consider context,
the affected person's needs and opportunities for correction. Maintainer
decisions can be challenged respectfully with additional evidence.

This is an original project policy, not a copied external code-of-conduct text.
