# Paper-source budget repair

Issue [#22](https://github.com/alohays/allagma/issues/22) was selected first on
12 October 2026 because a writer-accepted package could fail its own archive
reader. Issue #23 is the second selected, independent portability fix. The
existing toy-to-paper task already has PR #25; the assigned accessibility task
and owner-only historical-audio decision are separate work.

The repair plans the complete expanded source set, including exact serialized
provenance, before copying payloads. It checks the final bibliography and revised
manifest together after compilation and checks the inventory before archiving.
The ceiling remains 26,214,400 bytes and 1,000 regular files. Failed revisions
remain available; recovery requires a new output path.

## Acceptance evidence

| Requirement | Passing evidence |
| --- | --- |
| Pre-provenance boundary | The regression computes the old boundary from a real assembled fixture. It fails on main `174e200` and passes after repair. An exact final-byte limit still assembles, archives and unpacks with identical contents. |
| All generated bytes and final bibliography | The initial plan includes configuration, instructions, bibliography and provenance. A compiler-output fixture fits the old source plus `.bbl` budget but exceeds it when the new provenance entry is counted; it fails before archive creation and leaves the initial source and compiler output intact. |
| Early copy admission and changed inputs | A 65,536-byte declared copy at a 32,768-byte fixture ceiling causes zero copy calls and zero output files. Growth, shrinkage, same-size replacement and growth between stat and read are rejected; reading is bounded by the admitted size plus one detection byte. |
| Archive protections | Byte and file limits are applied before archive creation. Reader regressions preserve traversal, symlink, duplicate-name and expansion checks; the fitting archive round trip remains passing. |
| Real compilation | The optional packaged-entrypoint test passes with actual TeX Live 2024 and macOS isolation. The retained EMA paper rebuild also passes: eight pages, 42 source files, configured author `allagma`, and the unpacked builder executes successfully. PDF text/metadata checks pass; this change does not assert a new page-by-page visual review. |
| Preservation and recovery | Tests check input bytes/mtimes and retain failed outputs; retrying an existing revision is rejected. The branch changes no files under studies, evals, methods, contracts, media or project model settings. |

The [before log](evidence/paper-source-budget/before.log) retains three expected
failures against the original adapter, using the new regressions. The
[passing paper tests](evidence/paper-source-budget/regressions.log),
[real entrypoint test](evidence/paper-source-budget/real-tex-entrypoint.log) and
[validation receipt](evidence/paper-source-budget/validation.json) bind commands,
environment and implementation digests. Full offline conformance passes 199
tests; all 19 tooling tests and the catalog also pass.

The original default-limit observation remains: 26,214,400 admitted bytes plus
3,829 provenance bytes produced a 26,218,229-byte source that its reader rejected.
The original oversized probe copied 26,214,401 payload bytes before failure.
Re-executing the same retained probe against this repair rejects both sources
at admission, copies zero oversized payload bytes, and preserves inputs; see the
[default-limit receipt](evidence/paper-source-budget/default-limit.json).
Routine regressions use smaller limits without changing the production ceiling.

This is agent-assisted implementation and self-review of packaging behavior.
Fixture data is not a scientific finding. No native model session, scientific
campaign, network literature acquisition or submission is part of this repair.
The PR remains unmerged for review.
