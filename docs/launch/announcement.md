# Launch copy — prepared, not posted

## Short announcement

Allagma is a research workflow for coding agents: pin the plan and methods,
retain every attempt, and connect claims to evidence you can inspect. Try the
offline Python example, then explore three executed studies with reproducible
packages. Core is MIT; 0.3.0rc2 is a source release candidate.

Repository: [alohays/allagma](https://github.com/alohays/allagma).
At launch, add the live documentation and flagship demo links after verifying
them. Do not describe those endpoints as live before activation.

## Longer introduction

A coding agent can write an experiment. A researcher also needs to know which
plan it followed, what failed, which results were included, and whether a claim
survives recomputation. Allagma supplies portable methods and file-based records
for that part of the work. Scientific code and statistical choices stay with
the study.

The first example uses Python 3.11+ and the standard library, with no model
account or GPU. It runs a small estimator comparison, retains a real failure
and interruption, and produces a figure, report and auditable claims. One claim
is supported; an overstrong claim is contradicted by individual seeds.

The native workflow was evaluated in twelve fresh sessions across three local
tasks. All twelve completed the required science. Six of six Allagma packages
and four of six plain-Codex packages met the full evidence requirements. The
remaining two lacked explicit review-revision binding. This is a small local
result, not evidence of broad scientific superiority or consistent cost savings.

Contributions are welcome in documentation, methods, host qualification and
reproduction. Start with a small task and state exactly what your checks prove.
