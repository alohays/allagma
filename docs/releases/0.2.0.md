# Allagma 0.2.0

Status: local implementation, not a published release. The source snapshot and
acceptance report identify the exact qualified content. The existing project
license is MIT; design attribution is recorded separately.

This first implementation provides the I1–I5 portable foundation, replaceable
composition, contributor path, versioned-study tooling and complete toy research
walkthrough. The supported helper environment is Python 3.11+ on POSIX. The
generic path executes locally; Codex and Claude Code packaging is contract
checked. Real-model activation and scientific quality are separate unperformed
qualifications.

There are no earlier implemented public contracts to migrate. Evidence schema
0.2 rejects other versions rather than guessing compatibility. Minor releases
in 0.x may introduce explicit breaking changes; announce migrations and retain
the old bundles. Prompt edits change distributed content and require a new
immutable revision even when the contract version stays the same.

The acceptance update fixtures use **synthetic** later release labels to test
deprecation, retirement, pinning and rollback. They are not actual published
Allagma releases or evidence of improved research performance. Scaffold migration
examples are similarly explicit test transformations, separate from bundle
updates.

Before publication, rerun acceptance, check the support matrix and notices,
preserve the release asset inventory, and create the immutable tag through the
maintainer's normal release process. This implementation task does not publish
a release or submit a manuscript.
