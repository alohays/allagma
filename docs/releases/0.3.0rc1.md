# Allagma 0.3.0rc1 — qualification in progress

This release candidate is under evaluation. The 12-run comparison and final
release audit are not complete; do not interpret this version label as a
qualification claim. Follow [v0.3 requirements](../v0.3/requirements.md).

The candidate adds a reusable brief/material/resource workspace interface,
bounded local computation, native Codex session capture, separate model usage,
protected controller records, interrupted-request recovery and standalone
reproduction drivers. Scientific models, evaluators and analyses remain
study-owned. The default conformance kit and toy study remain offline and
standard-library-only. Native execution is optional and currently targets this
qualified macOS/CLI environment.

## Migration and compatibility

Shared record contracts remain version 0.2. Existing studies and campaigns keep
their exact bundled helpers and historical behavior. No old bundle, attempt or
publication is rewritten. Adopt updates only at a campaign boundary using the
existing Check/Plan/Reconcile/Validate/Adopt procedure. New brief-driven studies
can use [research prepare/run](../research-workspaces.md).

The updated analysis helper accepts one eligible confirmation run by default;
`minimum_confirmation_runs` lets the study require more. This is an availability
threshold, not an assertion that observations are independent or an uncertainty
method is justified. The toy study explicitly requires two. Paired conditions
may reuse a seed within a split only with `paired_seeds: true` and unique
nonempty `condition_id` values. Pilot/confirmation seed separation remains
enforced. Historical v0.2 helpers retain their old minimum and seed behavior.

Native session configuration is temporary and isolated. It preserves the user's
selected model controls and never creates project model pins. Model inference
uses the existing account; scientific compute runs locally under separate
finite limits. Agent tools and computation workers have distinct filesystem
profiles because the restricted native tool profile does not initialize MPS.
The common worker profile has passed actual MPS and protected-file/network
canaries. This does not claim adversarial containment or support for other hosts.

Final validated task, comparison, reproduction and limitation references will
be added after the required evidence is complete.
