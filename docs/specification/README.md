# Adopted v0.2 specification

These four owner-supplied documents define the implementation target:

- [Framework design and I1–I5](framework-design.md)
- [Module and contribution rules](allagma-module-and-contribution-plan.md)
- [Study version protocol](allagma-study-version-protocol.md)
- [Reference decisions](allagma-reference-decisions-2026-10-06.md)

They are exact imported snapshots, with original digests and source locations
in `provenance.json`. Obsidian wiki links refer to the original planning vault;
they are preserved to avoid changing the source evidence. The repository's
operational documentation uses ordinary Markdown links.

The scope is Allagma initialization and its toy research workflow. Noemetric's
physical-intelligence experiments are a separate study. Historical planning
completion records describe earlier work and do not establish implementation
or experimental success. Current evidence is in [the acceptance report](../acceptance.md).
