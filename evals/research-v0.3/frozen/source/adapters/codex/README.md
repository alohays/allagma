# Study-local codex instruction delivery.

Install generated entrypoints at `.agents/skills/allagma-*/SKILL.md`. Select or recover a campaign before reading methods. Resolve the bundle through its lock; do not substitute global skills. Shared method text is read from that immutable bundle.

No hooks, subagents, automatic provider calls or model overrides are installed. Missing command execution means the execution step is blocked while design can continue. Contract fixtures exercise registration, campaign routing and capability checks; they do not establish real-model research quality.

The optional `session.py` development adapter captures an explicitly requested
fresh native session on macOS. It uses existing authentication and snapshots the
selected user model/settings into an isolated runtime home outside the candidate
workspace. It never writes a project `.codex/config.toml`. Global skills and
instructions are excluded; the task supplies its own inputs and, where selected,
study-local Allagma methods. Filesystem permission profiles protect controller
material and read-only inputs while allowing workspace writes. Command network
access is disabled; prepare local dependencies before evaluation.

Native CLI 0.160.1 has passed a development canary for reading allowed input,
denying input modification and denying a controller-only answer file. Its first
two isolation attempts failed and remain recorded. This is not yet v0.3 research
workflow qualification. Exact settings, prompts, public tool traces, token usage
and model observations accompany each session. The caller must supply finite
study resource enforcement and inspect outcomes; a zero CLI exit code does not
establish task completion. The callback interface can service a common resource
broker without embedding scientific decisions in this adapter.
