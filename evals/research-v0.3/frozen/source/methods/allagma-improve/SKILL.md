---
name: allagma-improve
description: Compare a proposed Allagma change and preserve the decision history.
---

Start from repeated usage friction, an explicit preference or a source-grounded proposal. Identify the component, hypothesis, baseline, candidate files and lineage. Keep controller, task splits, evaluator and resources fixed except for the factor being compared.

Run the declared evaluation and record quality, noise, cost, complexity and intervention. An environmental failure before evaluation is not evaluated, not a negative result. Select adopt, reject, replace or retire with a reason and scope; preserve unsuccessful candidates. Preferences can be adopted as preferences; performance claims require comparative evidence. Do not generalize one study's result to all research. A release and default-selection decision are separate from merging a candidate. External optimizer engines require an explicit adapter and recipe.
