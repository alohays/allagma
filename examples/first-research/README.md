# Small inputs for a native research session

This brief and finite resource profile exercise the public `research prepare`
interface without supplying finished scientific code or reference answers.
Preparation is offline. Optional `research run` uses your authenticated Codex
account on the qualified macOS path and consumes model usage.

Follow [the native-study guide](../../docs/guides/native-study.md). Science must
use only Python's standard library, with a 120-second compute budget and a
30-second setup budget. A 900-second model session timeout is supplied separately
on the command line. These are ceilings, not claims about typical cost.

This is an original Allagma example under MIT. The completed default toy study
is a separate known-answer workflow; this brief asks the agent to develop its
own program and protocol. No native completion is implied by preparation alone.
