Turn the idea, existing resources and requested output into a StudySpec and readable brief. Record question, motivation, useful success conditions, constraints, available capabilities and stop rules. An unset budget stays unset. Continue authorized local design; ask only when missing information changes scope, cost or correctness.

Reference research is part of every new study. Follow [reference-research.md](reference-research.md): build the study's `references/map.json`, reading notes and concise `INDEX.md` before settling its question and baselines. Deduplicate primary papers and implementations; actively seek competing findings and record gaps. Verify bibliographic metadata separately from located passages and claim support. Record the effect on each later phase.

Use provided-only/offline mode when external retrieval is unavailable. State coverage limits; never imply a complete search. A known-answer toy can use a study-owned derivation and explicitly mark external literature as outside its scope. Retain important source assets through the optional bounded acquisition adapter before freezing scientific inputs. Ask before increasing adopted limits or accepting gated terms.
