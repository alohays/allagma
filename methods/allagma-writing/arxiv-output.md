# Optional paper output

Read the study's `paper.json`. `output: report` preserves the normal manuscript
output. If the researcher chooses `arxiv`, also produce a complete English paper,
compiled PDF and portable source archive through the optional arXiv adapter.
Never infer author identity: request configurable names, affiliations and optional
email/ORCID, or an explicit anonymous draft choice. Do not submit the paper.

Read the critical reference map and relevant passages, then outline the paper
before writing full paragraphs. Include abstract, introduction, related work,
methods, results, discussion, limitations, references and relevant appendices.
Retain negative and inconclusive findings. Scope comparisons to the actual data,
metrics, budgets and uncertainty. Reuse historical science only as a clearly
labeled new manuscript revision.

Generate empirical numbers and tables from hashed results. Bind figures to
their retained source hashes and claims to result locators. Cite verified
metadata and the source passages actually read. A correct DOI does not verify
support for an assertion. Apply humanizer to improve clarity while preserving
every fact, number, citation, uncertainty statement and scientific meaning.
Retain a scoped scientific review and a separate record of the prose review.

Use a configurable preprint template compatible with current official arXiv TeX
requirements. Include TeX, bibliography and bbl, figures, required custom styles,
instructions and provenance. Compile the unpacked archive in a clean environment
without network or reference-cache access. Check logs for unresolved references,
then render and inspect every PDF page for clipping, overlap and unreadable
figures/tables. Keep TeX installation and execution outside the offline core.
