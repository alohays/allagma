## What you see

The offline toy includes finished scientific programs. The local recording
workbench runs that code and displays its outputs. At 1:23, the film switches
to the retained **EMA r07 figure from a native Codex study**. That chapter shows
an existing result; it does not retrain the model or simulate an agent session.

| Time | Work and output |
| --- | --- |
| 0:00 | Read the research question and inputs |
| 0:12 | Run the study and retain its attempts |
| 0:32 | Inspect the generated paired-difference figure |
| 0:46 | Compare supported and contradicted claims |
| 1:01 | Read the generated manuscript |
| 1:13 | Recompute the result and check its evidence |
| 1:23 | Inspect the retained native EMA result |

For the native example, [read the completed EMA study](/allagma/studies/ema-schedule/)
and its qualifications. To use your own question, [prepare a native study](/allagma/guides/native-study/).
The researcher supplies the brief, materials and limits; the agent develops the
protocol, scientific code, analysis and report.

The 100-second footage is continuous, with automated navigation and no
accelerated computation. On-screen command paths are abbreviated. Narration
uses Kokoro's af_heart voice, generated locally from Apache-2.0 model weights;
the engine is MIT licensed. The [narration notices](/allagma/generated/media/demo/NARRATION-NOTICES.md)
identify the exact sources. The retained EMA figure was generated using
AI Scientist-adapted code and keeps its [separate license](/allagma/generated/media/evidence/EMA-LICENSE.txt).

The poster arranges the unchanged toy plot and a sentence from its manuscript,
with an annotation explaining the counterexamples. It is a presentation of
outputs, not a screenshot of a product interface.
[Movie provenance](/allagma/generated/media/demo/provenance.json),
[poster provenance](/allagma/generated/media/demo/results-poster-provenance.json)
and [capture instructions](https://github.com/alohays/allagma/blob/main/media/CAPTURE.md)
