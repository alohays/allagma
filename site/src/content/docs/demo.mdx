Watch a research brief become an executed offline study, a figure, an
evidence-linked report, and recomputed results. **100 seconds, actual software.**

<WorkflowVideo />

The first six chapters run the known-answer offline example through the shipped
recording workbench. The final chapter shows **retained EMA r07 results** from a
native agent study; it does not retrain that study or simulate a model session.
The footage is continuous, with automated browser navigation and no accelerated
computation. Command paths are abbreviated on screen. Narration is synthesized
locally with Kokoro's af_heart voice using Apache-2.0 model weights. The
[narration notices](/allagma/generated/media/demo/NARRATION-NOTICES.md) identify
the model, engine and source licenses.
