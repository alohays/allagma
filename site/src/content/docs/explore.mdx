This introductory example compares a sample mean with the same estimate plus
a fixed bias. It produces a figure and report with a useful distinction: the
average error increased, but it did not increase on every seed.

<StudyExplorer />

These selected files are unchanged outputs from the **offline toy study**,
which supplies its own scientific code. The complete study also retains its
inputs, protocol, raw measurements, failures and retries. No model is involved
in this example.

[Run the example locally](/allagma/guides/first-study/) to create that full
record and recompute the results. For work performed by a coding agent, read
the [completed native studies](/allagma/studies/).
