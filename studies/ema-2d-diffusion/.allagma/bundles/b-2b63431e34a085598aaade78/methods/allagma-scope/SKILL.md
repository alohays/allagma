---
name: allagma-scope
description: Scope a research question and record prior-work uncertainty.
---

Turn the idea, existing resources and requested output into a StudySpec and readable brief. Record question, motivation, useful success conditions, constraints, available capabilities and stop rules. An unset budget stays unset. Continue authorized local design; ask only when missing information changes scope, cost or correctness.

Build a literature/evidence map with source metadata, source location, support assessment and uncertainties as separate fields. A verified title or DOI does not verify support for a claim. If network access is unavailable, record the resulting literature limitation. A toy known-answer problem can use a study-owned mathematical derivation; do not imply scientific novelty.
