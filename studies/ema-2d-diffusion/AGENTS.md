# Study workspace

This scaffold belongs to the study. Allagma updates preserve it. Read
`ALLAGMA.md` (or the generated path recorded in `.allagma/ownership.json`) for
the selected recipe. Recover a campaign before choosing its method bundle.
Keep scientific code and evidence in the study. Do not edit generated bundles.

Preserve the user's GUI model selection; do not add project-level model or
review_model pins without an explicit request.

This is the native Codex qualification study. Activate the relevant local
Allagma skill, read its generated wrapper and `ALLAGMA.md`, resolve the method
through campaign `ema-v1`, then read that exact canonical skill and module
contract. Record commands and results. Never edit generated bundles or frozen
campaign materials. Keep native model defaults; do not pass model overrides.

Read `DESIGN.md` and `protocol.json`. Use `python3 manage.py` for scientific
work; it selects the isolated `.venv` interpreter and the campaign's pinned
helper and enforces the study-wide computation ledger. Operations are `start`,
`check`, `interrupt`, `pilot` (one next pilot), `freeze`, `confirm` (one next
confirmation), `analyze`, `audit`, and `status`. Do not call the runner directly
or change resource ceilings. Stop on a failed check or unsuccessful attempt
and report its evidence; a coordinator can inspect and authorize a repair.
Do not begin confirmation without `confirmation-freeze.json`. Preserve every
attempt and never label an interrupted one as scientific evidence. All public
technical text is English. Do not spawn additional agents or model sessions.
